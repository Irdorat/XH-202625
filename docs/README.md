# Documentation

This directory stores source documents and project reports.

```text
docs/
├── general/        # Proposal, competition context, and dataset description
└── baseline_v1/    # Baseline v1 results and conclusions
```

Use one subdirectory per stable project stage. Reports should state the dataset split, checkpoint, evaluation protocol, aggregate and per-class metrics, runtime environment, and known limitations.

Project documentation is written in English. Do not edit original organizer-provided PDF files.
