# Models

This directory separates external pretrained weights from checkpoints selected by the team.

```text
models/
├── pretrained/    # Original pretrained checkpoints
└── trained/       # Selected project checkpoints
```

The selected baseline v1 checkpoint is `trained/baseline_v1_best.pt`.

Model binaries are not committed to Git. Share them through versioned archives and include the model name, experiment name, expected filename, checksum, and corresponding configuration in the handoff notes.
